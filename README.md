# Marginalia

Upload a PDF, hear it read aloud, ask a question, then keep listening. Answers come from the book first, and from the web when the pages do not say.

**Repository:** [github.com/boss974829/marginalia](https://github.com/boss974829/marginalia)

## Open the app

```bash
git clone https://github.com/boss974829/marginalia.git
cd marginalia
npm install
npm run dev
```

Open the address printed by the dev server.

On Android, use the browser menu and choose **Add to Home screen**. Marginalia then opens full screen, like an app you installed.

A scanned PDF (a photo of pages, with no text layer) cannot be read. Use a normal digital PDF.

## What it does

- Reads the PDF aloud (Eve, Ara, Leo, or Helios)
- Lets you pause, skip, and change speed
- Answers questions from the book, or from the web when the book is silent
- Continues reading after the answer
- Keeps your place on this device

Languages for speech: English, Hindi, Spanish, French, German, and Arabic.
